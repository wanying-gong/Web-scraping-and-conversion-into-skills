# CompoundForm[](#compoundform "Link to this heading")

*class* CompoundForm[](#keysight.ads.de.db.CompoundForm "Link to this definition")
:   Bases: [`Form`](keysight.ads.de.db.Form.md#keysight.ads.de.db.Form "keysight.ads.de.db._forms.Form")

    CompoundForm is a type of Form for a parameter that contains one or more sub-parameters.

    The CompoundForm describes how the parameter is netlisted and displayed.
    The Form for each sub-parameter describes how that portion of the parameter is netlisted and displayed.
    The number of sub-parameters is fixed by the parameter definition.

        Parameters:
        :   * **name** (*str*) – Name of the form
            * **label** (*str*) – Descriptive label for the form.
            * **params** (*Sequence[ModelParam]*) – A sequence of sub-parameter definitions.
            * **net\_format** (*str*) – The netlist format string for values using this form.
              If empty, the default format string will be a comma separated list of sub-parameters.
            * **display\_format** (*str*) – The display format string for values using this form.
              If empty, the default format string will be a comma separated list of sub-parameters.
            * **dialog\_data** (*str*) – An optional string used by edit dialogs for this form.

        Example

        ```
        # A point is a compound form with two parameters, X and Y
        formset = de.db.model_lib.formsets["StdFormSet"]
        default_coordinate_value = de.db.std_string_param("0 mil")
        param_first = de.db.ModelParam("first", "x coordinate", formset)
        param_first.unit_type = de.db.ModelUnitType.LENGTH
        param_first.default_value = default_coordinate_value
        param_second = de.db.ModelParam("second", "y coordinate", formset)
        param_second.unit_type = de.db.ModelUnitType.LENGTH
        param_second.default_value = default_coordinate_value
        point_form = de.db.CompoundForm("PointForm", "x,y", [param_first, param_second])
        ```
