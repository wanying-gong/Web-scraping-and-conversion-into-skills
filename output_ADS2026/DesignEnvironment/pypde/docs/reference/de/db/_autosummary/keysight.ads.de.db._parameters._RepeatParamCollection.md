# \_RepeatParamCollection[](#repeatparamcollection "Link to this heading")

*class* \_RepeatParamCollection[](#keysight.ads.de.db._parameters._RepeatParamCollection "Link to this definition")
:   Bases: `_IndexedMutableCollection`[[`ParamNonRepeated`](keysight.ads.de.db.ParamNonRepeated.md#keysight.ads.de.db.ParamNonRepeated "keysight.ads.de.db._parameters.ParamNonRepeated"), `ParamNonRepeated`]

    A list-like collection of Param for repeated parameters.

    This class is designed to behave like a list, but the actual elements
    are stored in the repeated parameter. The repeats can be indexed
    like a list so a negative index starts from the end of the list.
