# ModelParam[](#modelparam "Link to this heading")

*class* ModelParam[](#keysight.ads.de.db.ModelParam "Link to this definition")
:   Bases: `object`

    ModelParam is a parameter definition that is a part of a model definition (see [`ModelDef`](keysight.ads.de.db.ModelDef.md#keysight.ads.de.db.ModelDef "keysight.ads.de.db.ModelDef")).

    Parameter values are stored in [`ParamItem`](keysight.ads.de.db.ParamItem.md#keysight.ads.de.db.ParamItem "keysight.ads.de.db.ParamItem") objects.
    Parameter values have associated forms that determine how the parameter
    is stored, netlisted and displayed (see [`Form`](keysight.ads.de.db.Form.md#keysight.ads.de.db.Form "keysight.ads.de.db.Form")).
    The allowed forms for a given parameter are listed in its formset (see [`Formset`](keysight.ads.de.db.Formset.md#keysight.ads.de.db.Formset "keysight.ads.de.db.Formset"))

    *property* default\_value*: [ParamItem](keysight.ads.de.db.ParamItem.md#keysight.ads.de.db.ParamItem "keysight.ads.de.db.ParamItem") | None*[](#keysight.ads.de.db.ModelParam.default_value "Link to this definition")
    :   The default value for the parameter.

        If the default\_value property is not set, the default value **must** be
        provided by a default value callback (a [`ModelCbBase`](keysight.ads.de.db.ModelCbBase.md#keysight.ads.de.db.ModelCbBase "keysight.ads.de.db.ModelCbBase")
        instance whose [`type`](keysight.ads.de.db.ModelCbBase.md#keysight.ads.de.db.ModelCbBase.type "keysight.ads.de.db.ModelCbBase.type") is
        [`PARAMETER_DEFAULT_VALUE`](keysight.ads.de._pde.ModelCbType.md#keysight.ads.de._pde.ModelCbType.PARAMETER_DEFAULT_VALUE "keysight.ads.de._pde.ModelCbType.PARAMETER_DEFAULT_VALUE")).

        When creating a ModelParam for a ModelDef in Python, the callback will
        be a [`ModelCb`](keysight.ads.de.db.ModelCb.md#keysight.ads.de.db.ModelCb "keysight.ads.de.db.ModelCb")
        (a [`ModelCbBase`](keysight.ads.de.db.ModelCbBase.md#keysight.ads.de.db.ModelCbBase "keysight.ads.de.db.ModelCbBase") implemented in Python).
        When inspecting existing models, this will either be a
        [`ModelCbAEL`](keysight.ads.de.db.ModelCbAEL.md#keysight.ads.de.db.ModelCbAEL "keysight.ads.de.db.ModelCbAEL") for AEL models or a
        [`ModelCb`](keysight.ads.de.db.ModelCb.md#keysight.ads.de.db.ModelCb "keysight.ads.de.db.ModelCb") for Python models.

        If the default\_value property and a
        [`PARAMETER_DEFAULT_VALUE`](keysight.ads.de._pde.ModelCbType.md#keysight.ads.de._pde.ModelCbType.PARAMETER_DEFAULT_VALUE "keysight.ads.de._pde.ModelCbType.PARAMETER_DEFAULT_VALUE")
        default value callback are both set,
        the value returned by the callback will take precedence.

        If you set the default\_value property, the
        [`ParamItem`](keysight.ads.de.db.ParamItem.md#keysight.ads.de.db.ParamItem "keysight.ads.de.db.ParamItem") you pass in as the default
        value may be modified to match the
        parameter definition.
