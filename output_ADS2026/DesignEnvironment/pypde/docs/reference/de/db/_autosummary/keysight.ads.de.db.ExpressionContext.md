    \_\_init\_\_()[](#keysight.ads.de.db.ExpressionContext.__init__ "Link to this definition")

    \_\_init\_\_(*design: DesignDbu | DesignUu*)
    :   Initialize an ExpressionContext.

        Parameters:
        :   **design** (*Optional[Design]*) – If provided, sets up the hierarchy for the given design.
            If not provided, the hierarchy must be set up prior to using
            the ExpressionContext.

        Example

        ```
        with de.db.ExpressionContext(design) as expr_context:
            expr_context.update_pcell_params(inst)

        with de.db.ExpressionContext() as expr_context:
            expr_context.setup_hierarchy_for_design(design)
            expr_context.evaluate_expression("Width * Length")
        ```

    *property* hierarchy\_context*: [DesignHierarchy](../../_autosummary/keysight.ads.de.DesignHierarchy.md#keysight.ads.de.DesignHierarchy "keysight.ads.de._core.design_hierarchy.DesignHierarchy")*[](#keysight.ads.de.db.ExpressionContext.hierarchy_context "Link to this definition")
    :   The hierarchy context used by this expression context.

        This will return an invalid DesignHierarchy if the hierarchy
        has not been set up.

    *property* is\_valid*: bool*[](#keysight.ads.de.db.ExpressionContext.is_valid "Link to this definition")
    :   True if the hierarchy has been set up.

    setup\_hierarchy\_for\_design(*design: DesignDbu | DesignUu*) → None[](#keysight.ads.de.db.ExpressionContext.setup_hierarchy_for_design "Link to this definition")
    :   Set up the hierarchy for the given design.

    setup\_hierarchy\_for\_layout\_only(*design: DesignDbu | DesignUu*) → None[](#keysight.ads.de.db.ExpressionContext.setup_hierarchy_for_layout_only "Link to this definition")
    :   Set up the hierarchy for layout only for the given design.

    evaluate\_expression(*expr: str*, *\**, *clear\_caches: bool = False*) → str[](#keysight.ads.de.db.ExpressionContext.evaluate_expression "Link to this definition")
    :   Evaluate the expression in this expression context and return the result.

        If clear\_caches is True, clear all the caches for this design before evaluating.

        Will raise an exception if the hierarchy has not been set up.

    update\_pcell\_params(*inst: InstanceDbu | InstanceUu*) → None[](#keysight.ads.de.db.ExpressionContext.update_pcell_params "Link to this definition")
    :   Update the PCell parameters of the given instance.

    clear\_design\_caches() → None[](#keysight.ads.de.db.ExpressionContext.clear_design_caches "Link to this definition")
    :   Clear all the caches for this design.

        Will raise an exception if the hierarchy has not been set up.

    push\_instance\_for\_reading(*inst: InstanceDbu | InstanceUu*) → None[](#keysight.ads.de.db.ExpressionContext.push_instance_for_reading "Link to this definition")
    :   Push the given instance onto the hierarchy stack for reading.

        This is useful to evaluate expressions in the context of a specific
        instance’s sub-design.

        Will raise an exception if the hierarchy has not been set up.

    pop() → None[](#keysight.ads.de.db.ExpressionContext.pop "Link to this definition")
    :   Pop the top instance off the hierarchy stack.

        Used to return to the previous level in the hierarchy after a push.

        Will raise an exception if the hierarchy has not been set up
        or if you are already at the root of the hierarchy.
