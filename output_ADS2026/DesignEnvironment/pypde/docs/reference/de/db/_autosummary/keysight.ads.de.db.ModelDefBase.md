# ModelDefBase[](#modeldefbase "Link to this heading")

*class* ModelDefBase[](#keysight.ads.de.db.ModelDefBase "Link to this definition")
:   Bases: `object`

    The model definition for a particular component or design.

    This defines the parameters, callbacks and other properties required to
    interpret and edit component instances.

    This is sometimes referred to as an item definition or component definition,
    but [`Term`](../../db_uu/_autosummary/keysight.ads.de.db_uu.Term.md#keysight.ads.de.db_uu.Term "keysight.ads.de.db_uu.Term") also has a shared ModelDef.

    :   Find the model definition for a cell.

        This function first identifies a cell, then returns that cell’s model definition
        or None if no model definition exists for the resolved cell.

        Parameters:
        :   * **lib\_or\_cell** (*Library | Cell*) –

              + If [`Library`](../../_autosummary/keysight.ads.de.Library.md#keysight.ads.de.Library "keysight.ads.de.Library"), `cell_name` is used to identify the cell in that library.
              + If [`Cell`](../../_autosummary/keysight.ads.de.Cell.md#keysight.ads.de.Cell "keysight.ads.de.Cell"), that cell is used directly and `cell_name` is ignored.
            * **cell\_name** (*Optional[str]*) – The name of the cell whose model definition is to be found. This parameter is required if `lib_or_cell` is a [`Library`](../../_autosummary/keysight.ads.de.Library.md#keysight.ads.de.Library "keysight.ads.de.Library").
