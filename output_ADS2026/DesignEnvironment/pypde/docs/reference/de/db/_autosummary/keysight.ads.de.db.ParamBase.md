# ParamBase[](#parambase "Link to this heading")

*class* ParamBase[](#keysight.ads.de.db.ParamBase "Link to this definition")
:   Bases: `object`

    Base class that holds both a parameter item and its definition.

    See [`ParamItem`](keysight.ads.de.db.ParamItem.md#keysight.ads.de.db.ParamItem "keysight.ads.de.db.ParamItem") and [`ModelParam`](keysight.ads.de.db.ModelParam.md#keysight.ads.de.db.ModelParam "keysight.ads.de.db.ModelParam").
    The most common use of this class is the `parameters` attribute
    of an [`Instance`](../../db_uu/_autosummary/keysight.ads.de.db_uu.Instance.md#keysight.ads.de.db_uu.Instance "keysight.ads.de.db_uu.Instance") or [`Term`](../../db_uu/_autosummary/keysight.ads.de.db_uu.Term.md#keysight.ads.de.db_uu.Term "keysight.ads.de.db_uu.Term").
