# ModelUnitType[](#modelunittype "Link to this heading")

*class* ModelUnitType[](#keysight.ads.de._pde.ModelUnitType "Link to this definition")
:   Bases: `Enum`

    Unit types for parameter definitions (ModelParam).

    Each parameter defined by a ModelParam has a unit type. This describes
    the physical quantity (e.g., frequency or resistance) and drives how
    values are interpreted, displayed and scaled
    (e.g., Hz vs kHz vs MHz for [`FREQUENCY`](#keysight.ads.de._pde.ModelUnitType.FREQUENCY "keysight.ads.de._pde.ModelUnitType.FREQUENCY")).
