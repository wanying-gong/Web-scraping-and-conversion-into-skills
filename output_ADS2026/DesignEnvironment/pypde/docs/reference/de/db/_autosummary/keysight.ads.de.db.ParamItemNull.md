    *property* form\_name*: str*[](#keysight.ads.de.db.ParamItemNull.form_name "Link to this definition")
    :   The name of the [`Form`](keysight.ads.de.db.Form.md#keysight.ads.de.db.Form "keysight.ads.de.db.Form") that describes this item’s value.

        The name must match one of the Forms in the parameter definition’s
        formset. Even when a ParamItem is not currently paired with its
        definition, many operations later associate the item with a
        [`ModelParam`](keysight.ads.de.db.ModelParam.md#keysight.ads.de.db.ModelParam "keysight.ads.de.db.ModelParam") (by parameter name); an invalid form name
        can cause errors at that point.
