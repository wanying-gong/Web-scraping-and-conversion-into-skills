# StringFormWithCallbacks[](#stringformwithcallbacks "Link to this heading")

*class* StringFormWithCallbacks[](#keysight.ads.de.db.StringFormWithCallbacks "Link to this definition")
:   Bases: [`StringForm`](keysight.ads.de.db.StringForm.md#keysight.ads.de.db.StringForm "keysight.ads.de.db._forms.StringForm")

    A StringForm with one or more callbacks implemented in Python.

    One callback is for validating parameter string values.
    Another callback is for providing a list of options for parameter values.
    Another callback is for providing data strings for netlisting.

        Parameters:
        :   * **name** (*str*) – Name of the form
            * **label** (*str*) – Descriptive label for the form.
            * **net\_format** (*str*) – The netlist format string for values using this form.
              If empty, the default format string will be the name.
            * **display\_format** (*str*) – The display format string for values using this form.
              If empty, the default format string will be the name.
            * **dialog\_data** (*str*) – An optional string used by edit dialogs for this form.
            * **option\_cb** – An optional callback function that returns a list of valid
              options for a parameter.
            * **valid\_cb** – An optional callback function that validates a string value.
            * **data\_cb** – An optional callback function that returns a list of data
              strings for use in netlisting.

        Example

        ```
        def validate_width(value: str) -> bool:
            width = float(value.strip('"'))
            return 0.1 <= width <= 10.0

        def layer_lpp_names(design: de.db_uu.Design) -> list[str]:
            return ["cond:drawing", "cond2:drawing", "hold:drawing"]

        def layer_id_for_netlist(param: de.db.ParamItem, design: de.db_uu.Design) -> list[str]:
            assert isinstance(param, de.db.ParamItemString)
            # Example param.value: '"cond:drawing"'
            # Split the value into layer and purpose, stripping quotes
            layer, purpose = [s.strip('"') for s in param.value.split(":")]
            # Get the layer and return it
            layer_id = de.db.LayerId.from_name(design, layer, purpose)
            return [str(layer_id.layer)]

        # We don't need all three callbacks, this is just an example.
        form = de.db.StringFormWithCallbacks(
            "LayerTextForm",
            "LayerTextForm",
            "%d",
            "%v",
            "InstSelectionForm",
            layer_lpp_names,
            validate_width,
            layer_id_for_netlist,
        )
        ```

    validate\_and\_set\_string\_value(*param: [ParamItem](keysight.ads.de.db.ParamItem.md#keysight.ads.de.db.ParamItem "keysight.ads.de.db.ParamItem")*, *value: str*) → [ParamItem](keysight.ads.de.db.ParamItem.md#keysight.ads.de.db.ParamItem "keysight.ads.de.db.ParamItem") | None[](#keysight.ads.de.db.StringFormWithCallbacks.validate_and_set_string_value "Link to this definition")
    :   Validate and set the string value for the given parameter.

        Parameters:
        :   * **param** (*ParamItem*) – A parameter whose value is to be set.
              This parameter should have this form in its formset.
            * **value** (*str*) – The potential new value for the parameter.
            * **See :class:`StringFormWithCallbacks` and :class:`StringFormWithAELCallbacks`**
            * **for more information about validation callbacks.**
            * **If this form has a validation callback, it will be called to validate the value.**
            * **If the value is not valid, None will be returned.**
            * **If the parameter is not a string, a new ParamItemString will be returned**
            * **using this form and the given value.**
            * **Otherwise, the parameter will be returned after being updated**
            * **to use this form and the given value.**
