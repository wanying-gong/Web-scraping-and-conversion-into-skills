# Transform[](#transform "Link to this heading")

*class* Transform[](#keysight.ads.de.db.Transform "Link to this definition")
:   Bases: `object`

    A helper class for transforming objects.

    The values of the offset (matrix.dx, matrix.dy), are unitless.
    If you use this Transform to transform a point or instance,
    the units of the offset must match the units of the point or instance.
