# PCBPad[](#pcbpad "Link to this heading")

*class* PCBPad[](#keysight.ads.de.db_uu.PCBPad "Link to this definition")
:   Bases: [`PCBBase`](keysight.ads.de.db_uu.PCBBase.md#keysight.ads.de.db_uu.PCBBase "keysight.ads.de.db_uu._db_x.PCBBase")

    Represents a PCB Pad instance in layout.

    The Pad can be a single layer pad, a pad with a specified drill layer,
    a pad with specified top and bottom layers, or a through pad.
