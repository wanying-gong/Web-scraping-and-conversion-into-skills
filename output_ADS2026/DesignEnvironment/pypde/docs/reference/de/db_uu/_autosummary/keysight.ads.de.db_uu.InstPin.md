# InstPin[](#instpin "Link to this heading")

*class* InstPin[](#keysight.ads.de.db_uu.InstPin "Link to this definition")
:   Bases: `object`

    Represents the physical connection between an instance terminal and a pin on the master design.

    Note: There is no design object that represents an instance pin. This class is for convenience
    so you can find the snap point and location of the pin from the master Design
    transformed into the instance’s coordinate space.
