# Database Objects[](#database-objects "Link to this heading")

Database objects refer to objects that are backed by an underlying OpenAccess database object.

All database objects inherit from the [`ApolloObject`](_autosummary/keysight.ads.de.db_uu.ApolloObject.md#keysight.ads.de.db_uu.ApolloObject "keysight.ads.de.db_uu.ApolloObject") class.
