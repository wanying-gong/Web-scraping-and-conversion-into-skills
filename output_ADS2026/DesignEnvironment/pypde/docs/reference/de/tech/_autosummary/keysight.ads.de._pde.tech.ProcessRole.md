    NOT\_DEFINED *= 0*[](#keysight.ads.de._pde.tech.ProcessRole.NOT_DEFINED "Link to this definition")
    :   `'NotDefined'` The layer has no process role defined so shapes have no meaning.

    NONE *= 0*[](#keysight.ads.de._pde.tech.ProcessRole.NONE "Link to this definition")
    :   `'None'` Deprecated alias for NOT\_DEFINED.

    CONDUCTOR *= 1*[](#keysight.ads.de._pde.tech.ProcessRole.CONDUCTOR "Link to this definition")
    :   `'Conductor'` Shapes on layers with this role represent conductors.

    SEMICONDUCTOR *= 2*[](#keysight.ads.de._pde.tech.ProcessRole.SEMICONDUCTOR "Link to this definition")
    :   `'Semiconductor'` Shapes on layers with this role represent semi-conductors and don’t connect electrically.

    DIELECTRIC *= 3*[](#keysight.ads.de._pde.tech.ProcessRole.DIELECTRIC "Link to this definition")
    :   `'Dielectric'` Shapes on layers with this role represent dielectrics and don’t connect electrically.

    CONDUCTOR\_VIA *= 4*[](#keysight.ads.de._pde.tech.ProcessRole.CONDUCTOR_VIA "Link to this definition")
    :   `'ConductorVia'` Shapes on layers with this role represent conductor vias and don’t connect electrically.

    SEMICONDUCTOR\_VIA *= 5*[](#keysight.ads.de._pde.tech.ProcessRole.SEMICONDUCTOR_VIA "Link to this definition")
    :   `'SemiconductorVia'` Shapes on layers with this role represent semi-conductor vias and don’t connect electrically.

    DIELECTRIC\_VIA *= 6*[](#keysight.ads.de._pde.tech.ProcessRole.DIELECTRIC_VIA "Link to this definition")
    :   `'DielectricVia'` Shapes on layers with this role represent dielectric vias and don’t connect electrically.

    CONDUCTOR\_SLOT *= 7*[](#keysight.ads.de._pde.tech.ProcessRole.CONDUCTOR_SLOT "Link to this definition")
    :   `'ConductorSlot'` Shapes on layers with this role represent a slot in a conductor layer.
        Slot layers are ignored by layout connectivity.

    SEMICONDUCTOR\_SLOT *= 8*[](#keysight.ads.de._pde.tech.ProcessRole.SEMICONDUCTOR_SLOT "Link to this definition")
    :   `'SemiconductorSlot'` Shapes on layers with this role represent a slot in a semi-conductor layer.
        Slot layers are ignored by layout connectivity.

    DIELECTRIC\_SLOT *= 9*[](#keysight.ads.de._pde.tech.ProcessRole.DIELECTRIC_SLOT "Link to this definition")
    :   `'DielectricSlot'` Shapes on layers with this role represent a slot in a dielectric layer.
        Slot layers are ignored by layout connectivity.

    DRC *= 10*[](#keysight.ads.de._pde.tech.ProcessRole.DRC "Link to this definition")
    :   `'DRC'` Shapes on layers with this role represent errors reported by the design rule checker.

    BOUNDARY *= 11*[](#keysight.ads.de._pde.tech.ProcessRole.BOUNDARY "Link to this definition")
    :   `'Boundary'` Shapes on layers with this role represent bounding regions.

    HEAT\_SOURCE *= 12*[](#keysight.ads.de._pde.tech.ProcessRole.HEAT_SOURCE "Link to this definition")
    :   `'HeatSource'` Shapes on layers with this role represent heat sources.

    COMPONENT\_BODY *= 13*[](#keysight.ads.de._pde.tech.ProcessRole.COMPONENT_BODY "Link to this definition")
    :   `'ComponentBody'` Shapes on layers with this role represent the body of a component.

    ANNOT\_INSTANCE\_NAME *= 15*[](#keysight.ads.de._pde.tech.ProcessRole.ANNOT_INSTANCE_NAME "Link to this definition")
    :   `'InstanceName'` Shapes on layers with this role are used for instance name annotation.
        Annotation layers are not usually included in manufacturing.

    ANNOT\_COMPONENT\_NAME *= 16*[](#keysight.ads.de._pde.tech.ProcessRole.ANNOT_COMPONENT_NAME "Link to this definition")
    :   `'ComponentName'` Shapes on layers with this role are used for component name annotation.
        Annotation layers are not usually included in manufacturing.

    ANNOT\_OTHER *= 17*[](#keysight.ads.de._pde.tech.ProcessRole.ANNOT_OTHER "Link to this definition")
    :   `'Annotation'` Shapes on layers with this role are used for general annotation.
        Annotation layers are not usually included in manufacturing.

    SOLDER\_MASK *= 18*[](#keysight.ads.de._pde.tech.ProcessRole.SOLDER_MASK "Link to this definition")
    :   `'SolderMask'` The layer represents a solder mask.
        This is a negative layer so shapes on layers with this role cause an absence of solder.

    SOLDER\_PASTE *= 19*[](#keysight.ads.de._pde.tech.ProcessRole.SOLDER_PASTE "Link to this definition")
    :   `'SolderPaste'` The layer represents solder paste.
        This is a positive layer so shapes on layers with this role cause the presence of solder paste.

    SILK\_SCREEN *= 20*[](#keysight.ads.de._pde.tech.ProcessRole.SILK_SCREEN "Link to this definition")
    :   `'SilkScreen'` The layer contains text and annotation intended for manufacturing.

    SCRATCH *= 21*[](#keysight.ads.de._pde.tech.ProcessRole.SCRATCH "Link to this definition")
    :   `'Scratch'` The layer is used for temporary editing.
        Scratch layers are not included in manufacturing output.

    OTHER *= 22*[](#keysight.ads.de._pde.tech.ProcessRole.OTHER "Link to this definition")
    :   `'Other'` The layer has a role not covered by the other values but is intended for manufacturing.

    :   Return the string representation of the ProcessRole.
