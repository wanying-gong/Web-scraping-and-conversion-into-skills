# Mode[](#mode "Link to this heading")

*class* Mode[](#keysight.ads.de._pde.tech.Thermal.Mode "Link to this definition")
:   Bases: `Enum`

    Defines the mode of a Thermal Relief.

    Attributes

    |  |  |
    | --- | --- |
    | [`USE_DEFAULT`](#keysight.ads.de._pde.tech.Thermal.Mode.USE_DEFAULT "keysight.ads.de._pde.tech.Thermal.Mode.USE_DEFAULT") | `'UseDefault'` Use the thermal mode defined in the default PadLayerEntry. |
    | [`FULL_CONNECT`](#keysight.ads.de._pde.tech.Thermal.Mode.FULL_CONNECT "keysight.ads.de._pde.tech.Thermal.Mode.FULL_CONNECT") | `'FullConnect'` The pad is fully connected to the plane. |
    | [`STRAIGHT`](#keysight.ads.de._pde.tech.Thermal.Mode.STRAIGHT "keysight.ads.de._pde.tech.Thermal.Mode.STRAIGHT") | `'Straight'` The thermal has 4 spokes. |
    | [`EXACT`](#keysight.ads.de._pde.tech.Thermal.Mode.EXACT "keysight.ads.de._pde.tech.Thermal.Mode.EXACT") | `'Exact'` The thermal has 4 spokes. |
    | [`STRAIGHT_2`](#keysight.ads.de._pde.tech.Thermal.Mode.STRAIGHT_2 "keysight.ads.de._pde.tech.Thermal.Mode.STRAIGHT_2") | `'Straight2'` The thermal has 2 spokes. |
    | [`EXACT_2`](#keysight.ads.de._pde.tech.Thermal.Mode.EXACT_2 "keysight.ads.de._pde.tech.Thermal.Mode.EXACT_2") | `'Exact2'` The thermal has 2 spokes. |
    | [`str`](#keysight.ads.de._pde.tech.Thermal.Mode.str "keysight.ads.de._pde.tech.Thermal.Mode.str") | Return the string representation of the Thermal Mode. |

    USE\_DEFAULT *= 0*[](#keysight.ads.de._pde.tech.Thermal.Mode.USE_DEFAULT "Link to this definition")
    :   `'UseDefault'` Use the thermal mode defined in the default PadLayerEntry.

    FULL\_CONNECT *= 1*[](#keysight.ads.de._pde.tech.Thermal.Mode.FULL_CONNECT "Link to this definition")
    :   `'FullConnect'` The pad is fully connected to the plane. There is no thermal relief.

    STRAIGHT *= 3*[](#keysight.ads.de._pde.tech.Thermal.Mode.STRAIGHT "Link to this definition")
    :   `'Straight'` The thermal has 4 spokes. The clearance is drawn with straight lines.

    EXACT *= 4*[](#keysight.ads.de._pde.tech.Thermal.Mode.EXACT "Link to this definition")
    :   `'Exact'` The thermal has 4 spokes. The clearance is drawn with with rounded corners to keep exact distance.

    STRAIGHT\_2 *= 6*[](#keysight.ads.de._pde.tech.Thermal.Mode.STRAIGHT_2 "Link to this definition")
    :   `'Straight2'` The thermal has 2 spokes. The clearance is drawn with straight lines.

    EXACT\_2 *= 7*[](#keysight.ads.de._pde.tech.Thermal.Mode.EXACT_2 "Link to this definition")
    :   `'Exact2'` The thermal has 2 spokes. The clearance is drawn with with rounded corners to keep exact distance.

    *property* str[](#keysight.ads.de._pde.tech.Thermal.Mode.str "Link to this definition")
    :   Return the string representation of the Thermal Mode.
