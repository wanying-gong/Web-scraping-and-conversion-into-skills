# Cell[](#cell "Link to this heading")

*class* Cell[](#keysight.ads.de.Cell "Link to this definition")
:   Bases: [`DMContainer`](keysight.ads.de.DMContainer.md#keysight.ads.de.DMContainer "keysight.ads.de._core.dmfile.DMContainer")

    A cell represents a logical or physical component of a design.

    Cells are contained in libraries and are containers for views, which typically hold the actual design data.
