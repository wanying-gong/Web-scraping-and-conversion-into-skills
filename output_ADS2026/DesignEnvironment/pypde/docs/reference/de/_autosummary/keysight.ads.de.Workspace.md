# Workspace[](#workspace "Link to this heading")

*class* Workspace[](#keysight.ads.de.Workspace "Link to this definition")
:   Bases: `object`

    An ADS Workspace for organizing your design work.

    A Workspace encapsulates a directory used by ADS to organize design work in a `Library:Cell:View`
    hierarchy. An open workspace is required to access libraries and designs contained in or referenced by
    the workspace.

    It contains libraries, references to other libraries, simulation data, data display files, and other data files.
