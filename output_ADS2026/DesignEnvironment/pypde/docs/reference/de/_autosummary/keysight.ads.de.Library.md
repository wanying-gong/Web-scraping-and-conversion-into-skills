# Library[](#library "Link to this heading")

*class* Library[](#keysight.ads.de.Library "Link to this definition")
:   Bases: [`DMContainer`](keysight.ads.de.DMContainer.md#keysight.ads.de.DMContainer "keysight.ads.de._core.dmfile.DMContainer")

    A library is a subdirectory in an ADS workspace that contains cells.

    Libraries may be used by adding them to a [`Workspace`](keysight.ads.de.Workspace.md#keysight.ads.de.Workspace "keysight.ads.de.Workspace") or by specifying the path in a library definition file ([`LibDef`](keysight.ads.de.LibDef.md#keysight.ads.de.LibDef "keysight.ads.de.LibDef")).

    A library does not have to physically reside in the workspace directory.

    All types of designs are contained in a library.
