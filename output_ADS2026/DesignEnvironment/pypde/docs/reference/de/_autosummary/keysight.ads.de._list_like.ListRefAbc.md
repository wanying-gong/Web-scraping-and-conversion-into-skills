# ListRefAbc[](#listrefabc "Link to this heading")

*class* ListRefAbc[](#keysight.ads.de._list_like.ListRefAbc "Link to this definition")
:   Bases: [`ReadableListRefAbc`](keysight.ads.de._list_like.ReadableListRefAbc.md#keysight.ads.de._list_like.ReadableListRefAbc "keysight.ads.de._list_like.ReadableListRefAbc")[`T`]

    An abstract base class (ABC) for a mutable list-like collection of elements.

    This is used to support cases where the elements are controlled
    by the owner.
    Assigning elements will assign the new objects to the owner.
    Inserting or appending new elements will add the new objects to the owner.
    Deleting an element from the collection will remove it from the owner.
