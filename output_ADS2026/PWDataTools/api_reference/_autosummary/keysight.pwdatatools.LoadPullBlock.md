# LoadPullBlock[](#loadpullblock "Link to this heading")

*class* LoadPullBlock[](#keysight.pwdatatools.LoadPullBlock "Link to this definition")
:   A collection of Vars that represents load pull data.

    Load pull is a process by which the impedance presented to a device under
    test is systematically varied in order to assess its performance.

    Examples

    ```
    >>> from keysight import pwdatatools as pwdt
    ```

    Instantiate a LoadPullBlock with a gamma ivar, using the default
    naming pattern for the gamma idxname:

    ```
    >>> data = {
    ...     'GammaLoad': [0.5 + 0.4j, 0.4 + 0.1j, 0.3 + 0.2j],
    ...     'iGammaLoad': [0, 1, 2],
    ...     'Gain': [10, 11, 12]
    ... }
    >>> lpblock = pwdt.LoadPullBlock(data, gamma_ivarname='GammaLoad')
    >>> lpblock.gamma_ivarname
    'GammaLoad'
    >>> lpblock.gamma_idxname
    'iGammaLoad'
    ```

    Since the default naming pattern was used for gamma\_idxname, we
    did not have to specify it during initialization.

    Instantiate a LoadPullBlock with a gamma ivar and a power ivar. Note
    that when gamma and power are swept, the power sweep is always the
    inner sweep.

    ```
    >>> data = {
    ...     'GammaLoad': [0.5 + 0.4j, 0.5 + 0.4j, 0.4 + 0.1j, 0.4 + 0.1j],
    ...     'iGammaLoad': [0, 0, 1, 1],
    ...     'PSource': [-10.0, -8.0, -10.0, -8.0],
    ...     'iPSource': [0, 1, 0, 1],
    ...     'Gain': [10, 11, 12, 10.5, 11.5]
    ... }
    >>> lpblock = pwdt.LoadPullBlock(
    ...     data,
    ...     gamma_ivarname='GammaLoad',
    ...     power_ivarname='PSource',
    ... )
    >>> lpblock.gamma_ivarname
    'GammaLoad'
    >>> lpblock.gamma_idxname
    'iGammaLoad'
    >>> lpblock.power_ivarname
    'PSource'
    >>> lpblock.power_idxname
    'iPSource'
    ```

    Since we did not specify the power\_idxname, it was assumed to be
    “iPSource”, which is the default naming pattern (“i” + “PSource”).

    See also

    The `read_file_as_loadpullblock()`
    function is the easiest way to instantiate a LoadPullBlock from a
    file. For more detailed information and examples, see
    [Work with Load Pull Data](../../howto/work_with_loadpull_data.md#work-with-load-pull-data).
