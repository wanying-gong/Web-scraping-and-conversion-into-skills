# Write a File[](#write-a-file "Link to this heading")

Data Tools has several functions and methods to write datafiles. You can use `write_file()`, [`Group.to_file()`](../api_reference/_autosummary/keysight.pwdatatools.Group.to_file.md#keysight.pwdatatools.Group.to_file "keysight.pwdatatools.Group.to_file"), or [`Block.to_file()`](../api_reference/_autosummary/keysight.pwdatatools.Block.to_file.md#keysight.pwdatatools.Block.to_file "keysight.pwdatatools.Block.to_file").

Before you attempt to write a file, make sure it is one of the supported file formats in `pwdatatools.options.writing.formats`.
