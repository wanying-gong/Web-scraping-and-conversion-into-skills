# keysight.pwdatatools.DataFile.is\_same[](#keysight-pwdatatools-datafile-is-same "Link to this heading")

DataFile.is\_same(*other\_datafile: str | PathLike | [DataFile](../index.md#keysight.pwdatatools.DataFile "keysight.pwdatatools._api.datafile.DataFile")*)[](#keysight.pwdatatools.DataFile.is_same "Link to this definition")
:   Return True if other datafile has same contents as instance.

    Only works for non-binary files like .txt, .mdf, .mdm, loadpull
    files, etc. Not supported for .ds or HDF5. Blank lines are
    ignored.

    Parameters:
    :   **other\_datafile** – Another file to compare against, as a str path, a
        `pathlib.Path`, or a `pwdatatools.DataFile`.

    Returns:
    :   True if other file has same contents as instance, False
        otherwise.

    Return type:
    :   *bool*

    Raises:
    :   **UnicodeDecodeError** – If file is not Unicode or ASCII.
