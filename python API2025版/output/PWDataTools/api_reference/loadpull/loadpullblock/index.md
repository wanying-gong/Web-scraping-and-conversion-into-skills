# LoadPullBlock[](#loadpullblock "Link to this heading")

This page documents public attributes and methods available in the LoadPullBlock class. For more information and examples, see [Load Pull Examples](../../../examples/loadpull/index.md#load-pull-examples).

*class* LoadPullBlock(*variables: Variables = None*, *\**, *name: str | None = None*, *gamma\_ivarname: str | None = None*, *gamma\_idxname: str | None = None*, *z\_ivarname: str | None = None*, *z\_idxname: str | None = None*, *power\_ivarname: str | None = None*, *power\_idxname: str | None = None*, *outer\_ivarnames: Iterable[str] | None = None*, *outer\_idxnames: Iterable[str] | None = None*, *exprs: ExprsDictLike | None = None*, *attrs: AttrsDictLike | None = None*, *copy: bool = False*, *\*\*kwargs*)[](#keysight.pwdatatools.LoadPullBlock "Link to this definition")
:   An object to store and manipulate load pull data.

    Parameters:
    :   * **variables** (*DataFrame, sequence of Var, str to VarLike mapping, or None*) – Several types of inputs are supported: a pandas DataFrame, a
          mapping of str variable name to ArrayLikes or Vars, or a sequence
          of Vars. Examples of ArrayLike objects are numpy ndarrays and
          MaskedArrays, Python lists, and pandas Series. If a mapping or
          sequence is provided, all data objects must have the same length
          for axis 0.
        * **name** (*str, optional*) – A str name for the LoadPullBlock. If not specified, the name is set
          to an empty string.
        * **gamma\_ivarname** (*str, optional*) – The name of the gamma independent variable. A LoadPullBlock
          must have either a gamma ivar or a z ivar, but not both.
        * **gamma\_idxname** (*str, optional*) – The name of the gamma indepedent variable’s index.
        * **z\_ivarname** (*str, optional*) – The name of the impedance independent variable. A LoadPullBlock
          must have either a gamma ivar or a z ivar, but not both.
        * **z\_idxname** (*str, optional*) – The name of the impedance indepedent variable’s index.
        * **power\_ivarname** (*str, optional*) – The name of the power independent variable.
        * **power\_idxname** (*str, optional*) – The name of the power indepedent variable’s index.
        * **outer\_ivarnames** (*iterable of str, optional*) – The names of the outer independent variables. Outer ivars can be
          any arbitrary swept variables, such as frequency, bias, etc.
        * **outer\_idxnames** (*iterable of str, optional*) – The names of the outer indepedent variable’s indexes.
        * **exprs** (*ExprsDictLike, optional*) – A mapping of str expression name to Expr objects. The Expr objects
          represent expressions that can be applied to variables or other
          expressions.
        * **attrs** (*dict-like, optional*) – A dict or dict-like object of arbitrary Block-level metadata. The
          keys must be strings and the values must be one of the following:
          str, int, float, complex, bool, None, dict, list, or
          numpy.ndarray. Nested dicts and lists are allowed.

    Other Parameters:
    :   * **data** (*DataFrame, str to ArrayLike mapping, or None*) – A keyword-only argument that exists mostly for backwards
          compatibility. It is recommended to use variables instead of this
          keyword-only argument. You cannot specify values for both data
          and variables.
        * **idxnames** (*iterable of str, optional*) – The names of the indexes. This is another way to define the
          names of the gamma, z, power, and outer indexes. To use this
          argument, you must also specify ivarnames and variables
          input must contain Vars with the proper gamma/z/power roles.
          Defaults to `None`.
        * **ivarnames** (*iterable of str, optional*) – The names of the independent variables. This is another way
          to define the names of the gamma, z, power, and outer
          independent variables. To use this argument, variables
          input must contain Vars with the proper gamma/z/power roles.
          Defaults to `None`.

    Notes

    If an ivarname is provided and its associated idxname is not
    provided, then its idxname is assumed to be “i” + “ivarname”.
    For example, if gamma\_ivarname is “GammaLoad” and gamma\_idxname
    is not provided, then gamma\_idxname is assumed to be “iGammaLoad”.

    Examples

    ```
    >>> from keysight import pwdatatools as pwdt
    ```

    Instantiate a LoadPullBlock with a gamma ivar, using the default
    naming pattern for the gamma idxname:

    ```
    >>> data = {
    ...     'GammaLoad': [0.5 + 0.4j, 0.4 + 0.1j, 0.3 + 0.2j],
    ...     'iGammaLoad': [0, 1, 2],
    ...     'Gain': [10, 11, 12]
    ... }
    >>> lpblock = pwdt.LoadPullBlock(data, gamma_ivarname='GammaLoad')
    >>> lpblock.gamma_ivarname
    'GammaLoad'
    >>> lpblock.gamma_idxname
    'iGammaLoad'
    ```

    Since the default naming pattern was used for gamma\_idxname, we
    did not have to specify it during initialization.

    Instantiate a LoadPullBlock with a gamma ivar and a power ivar. Note
    that when gamma and power are swept, the power sweep is always the
    inner sweep.

    ```
    >>> data = {
    ...     'GammaLoad': [0.5 + 0.4j, 0.5 + 0.4j, 0.4 + 0.1j, 0.4 + 0.1j],
    ...     'iGammaLoad': [0, 0, 1, 1],
    ...     'PSource': [-10.0, -8.0, -10.0, -8.0],
    ...     'iPSource': [0, 1, 0, 1],
    ...     'Gain': [10, 11, 12, 10.5, 11.5]
    ... }
    >>> lpblock = pwdt.LoadPullBlock(
    ...     data,
    ...     gamma_ivarname='GammaLoad',
    ...     power_ivarname='PSource',
    ... )
    >>> lpblock.gamma_ivarname
    'GammaLoad'
    >>> lpblock.gamma_idxname
    'iGammaLoad'
    >>> lpblock.power_ivarname
    'PSource'
    >>> lpblock.power_idxname
    'iPSource'
    ```

    Since we did not specify the power\_idxname, it was assumed to be
    “iPSource”, which is the default naming pattern (“i” + “PSource”).

    The [`read_file_as_loadpullblock()`](../../fileio/read_file_as_loadpullblock.md#keysight.pwdatatools._api.funcs.read_file_as_loadpullblock "keysight.pwdatatools._api.funcs.read_file_as_loadpullblock")
    function is the easiest way to instantiate a LoadPullBlock from a
    file. For more detailed information and examples, see
    [Work with Load Pull Data](../../../howto/work_with_loadpull_data.md#work-with-load-pull-data).
